================================================================
    共享单车多传感器数据采集与健康检测系统

    第七章  F2 — 链条异响检测
================================================================



7.1  核心挑战：区分链条异响与环境噪音
================================================================

F2 链条异响检测是三级检测体系中算法复杂度最高的一环。其核心难题可
用一句话概括：**如何仅凭麦克风音频，区分链条的周期性金属冲击声与
风噪、车流、人声等环境噪音？**

在本项目的实际工作场景中，巡检人员在户外骑行，手机麦克风面临的声学
环境极为复杂：

  · 风噪：骑行速度 15~20 km/h 时，麦克风端口的风压可产生 50~65 dB SPL
    的宽带噪声，频谱主要分布在 500 Hz 以下，但高风速时向中高频延伸。
  · 车流噪声：机动车经过时产生 60~80 dB SPL 的非平稳宽带噪声，峰值
    集中在 500~2000 Hz 区间。
  · 人声与环境音：行人交谈、施工噪音、鸟鸣等随机声学事件。

如果仅比较音量或频谱能量——"声音大就是异响"——则风噪天或繁忙路段
的误报率将高到不可接受。区分链条异响与环境噪音的关键差异化特征
在于：**链条异响具有与踏频严格锁定的周期性**。



7.2  理论基础：包络谱与倒谱
================================================================

7.2.1  包络谱分析 (Envelope Spectrum Analysis)

链条的金属冲击声在声学上可建模为一种调幅（Amplitude Modulation）
过程。踏频约 2~5 Hz 的低频调制信号（踩踏节奏）控制着 2~4 kHz 的
高频载波（链条金属共振频带）的强度——踩下踏板时链条张紧产生冲击，
2~4 kHz 频带能量骤升；踏板经过上死点后链条松弛，该频带能量骤降。

包络谱分析正是检测这种调幅特征的标准工具。其数学流程为：

  Step A — 带通滤波，提取 2~4 kHz 频带信号。该频带对应链条-牙盘
  金属接触的声学共振区，滤除了低频风噪和骑行者的身体振动。

  Step B — 希尔伯特变换（Hilbert Transform），计算解析信号：

      x_a(t) = x(t) + j × H{x(t)}

      其中 H{·} 为希尔伯特变换。解析信号的模即为包络：

      e(t) = |x_a(t)| = √(x(t)² + H{x(t)}²)

      物理直觉：e(t) 是高频振动的"轮廓线"，描绘了每个时刻 2~4 kHz
      频带的能量水平。冲击时刻 e(t) 高，间隙时刻 e(t) 低。

  Step C — 低通滤波，保留 0.5~10 Hz 的包络变化（踏频范围），滤除
  更高频的能量波动。

  Step D — 对包络信号做 FFT，得到包络谱。包络谱中踏频处的峰值
  反映了"链条冲击的周期性强弱"。

  Step E — 计算踏频处 SNR：

      SNR(dB) = 20 × log₁₀(峰值 / 噪声基底)

      噪声基底取 >15 Hz 频段的中位数（该频段无周期性结构，代表
      随机环境噪声的包络谱本底）。

7.2.2  倒谱分析 (Cepstrum Analysis)

倒谱是处理周期性冲击信号的另一经典工具，由 Bogert、Healy 和 Tukey
于 1963 年首次提出。其定义为：

    Cepstrum = |IFFT(log(|FFT(x)|))|²

  计算步骤：(1) 对信号做 FFT 得到功率谱，(2) 取对数，(3) 做逆 FFT
  得到倒谱（Cepstrum），(4) 对倒谱再做 FFT 得到倒谱的功率谱。

  倒谱横轴的单位为"倒频率"（Quefrency，单位：秒），每一倒频率峰值
  对应时域中一个特定周期的冲击模式。例如，若信号中存在周期为 0.4 秒
  （2.5 Hz 踏频）的冲击，则倒谱在 0.4 秒位置会出现显著峰值。

  倒谱的核心优势在于对周期性的敏感度高于直接 FFT——因为"取对数"操作
  压缩了动态范围，使幅度较低的周期性成分与幅度高的非周期成分站在同
  一起跑线上。这一特性恰好契合链条异响检测的场景：链条冲击声的绝对
  音量可能远低于环境噪音（如卡车经过），但其周期性在倒谱中依然清晰。

  本文在目标倒频率 1/pedal_freq ±15% 范围内计算 SNR：

      SNR = 峰值 / 噪声基底中位数

  将 SNR 映射到 [0, 1]：SNR ≥ 8 → 1（强烈周期性冲击），SNR ≤ 2 → 0。

7.2.3  双通道独立验证的设计哲学

包络谱和倒谱从两个不同的数学域出发，独立地检测同一种物理现象——周期性
冲击。包络谱关注"被调幅的高频载波中是否存在低频周期调制"，倒谱关
注"信号频谱的频谱中是否存在周期性结构"。两者互为验证：

  · 真正的链条异响：包络谱 SNR 高 AND 倒谱得分高（一致指向周期性）
  · 风噪：包络谱 SNR 低 AND 倒谱得分低（无周期结构）
  · 卡车鸣笛：包络谱 SNR 可能中高（短时强能量），但倒谱得分低
    （非周期性冲击，功率谱无双峰结构）

这种双通道冗余设计是本算法不需要训练数据的关键：物理规律的一致性
即可排除大部分误报场景。



7.3  算法流程
================================================================

detect_chain_noise() 的完整流程包含 12 个步骤。

7.3.1  预处理阶段（Step 1~3）

  Step 1 — 采样率估计与重采样至 8 kHz。

    从音频时间戳元数据文件计算原始采样的实际速率（Δ采样数/Δ时间），
    防御性限制在 1000~96000 Hz 范围内。若实际速率与 8 kHz 差异超过
    100 Hz，则使用 SciPy 的 signal.resample() 重采样到 8 kHz。

    选择 8 kHz 的理由：根据奈奎斯特定理，8 kHz 可分析的最高频率为
    4 kHz，恰好覆盖链条金属冲击的共振频带（2~4 kHz）。更高采样率
    不会带来额外的有效信息，仅增大计算开销。

  Step 2 — 踏频估计。

    当外部未提供踏频（pedal_freq_hz = None）时，通过自相关法自动
    估算。对低通滤波后的希尔伯特包络计算自相关，在延迟 0.2~1.0 秒
    （对应 1~5 Hz 踏频）范围内寻找最大峰值，取 1/延迟 作为踏频。
    回退值为 2.0 Hz。

    当外部提供了 F1 输出的 wheel_freq_hz 时（即踏频 ≈ 轮频），
    直接使用，省去自相关步骤并提高估计精度。

  Step 3 — 带通滤波 2~4 kHz。

    4 阶 Butterworth 带通滤波，提取链条冲击共振频带。低频截止 2 kHz
    可有效压制风噪的主能量区（<500 Hz），高频截止 4 kHz 滤除超出
    奈奎斯特范围的无效成分。

7.3.2  特征提取阶段（Step 4~10）

  Step 4 — 希尔伯特包络提取。

    对滤波后的 8 kHz 信号做 Hilbert 变换，取解析信号的绝对值作为
    包络信号 e(t)。该包络反映了 2~4 kHz 频带在每个时刻的能量水平。

  Step 4.5 — 包络调制深度（新增特征）。

    链条异响的本质是强烈的振幅调制。量化这种调制强度最直接的指标
    是包络信号的变异系数：

        mod_depth = std(envelope) / mean(envelope)

    正常骑行虽也有踏频周期的能量波动（正常踏板运动），但调制幅度
    平缓（mod_depth 约 0.5~0.7）。链条异响因金属冲击的瞬态特性，
    调制幅度非常大（包络在冲击时刻飙升至正常值的数倍）。该特征
    作为包络谱 SNR 的补充维检，单独评估"是否有强烈的冲击调制行为"。

  Step 5 — 包络低通滤波。

    对包络信号做低通滤波（0.5~10 Hz），仅保留踏频及其低次谐波范围
    的包络变化。滤波后的包络不会因环境噪音的短时能量波动而产生
    虚假的周期结构。

  Step 6 — 包络谱 SNR @ 踏频。

    对低通包络做 FFT → 包络谱 → 计算踏频处 SNR。SNR 越高，链条
    周期性冲击特征越强。正常骑行 SNR 约 3~10 dB（轻微的周期调制），
    链条异响 SNR 显著升高（>10 dB）。

  Step 7 — 谐波检测。

    检测包络谱中是否存在踏频的 2 次、3 次谐波。链条金属冲击的非
    线性特性（非正弦冲击）会自然产生谐波。检测方法：对每个谐波
    位置计算峰值是否高于噪声基底 2 倍（约 6 dB），返回检测到的
    谐波比例（0~1）。

  Step 8 — 冲击相位一致性。

    链条异响发生在曲柄的固定相位（如踏板通过下死点时链条张紧）。
    这意味着包络峰值之间的时间间隔应该锁定在踏频周期的整数倍。
    计算峰-峰间隔的圆形方差：

        R = |mean(e^(j×2π×相位))|

    R → 1 表示所有间隔对齐到同一相位（链条特征），R → 0 表示
    间隔随机散布（环境噪音特征）。

  Step 9 — Cepstrum 周期性得分。

    对滤波后信号计算倒谱，在目标倒频率 ±15% 范围内计算 SNR，映射
    到 [0, 1]。得分 >0.6 表示倒谱中存在清晰的周期结构。

  Step 10 — 辅助特征。

    高频能量比：2~4 kHz 频带能量占全频带能量的比例。链条冲击能量
    集中在这一频带，而风噪能量集中在低频。
    峰值因子：信号绝对最大值 / RMS。冲击型信号的峰值因子显著高于
    连续型信号。

7.3.3  评分阶段（Step 11~12）

  Step 11 — 异常得分融合。

    **11a — 基线偏移校准。**

    正常骑行必然产生踏频周期的包络调制（正常的踩踏运动本身就有
    周期性的能量波动）。如果将所有调制都算作"异常"，则正常骑行的
    F2 得分将偏低。解决方法是为每个特征设定一个"正常基线"——只有
    超过基线的量才计入异常得分：

      snr_score   = max(SNR - 10.0, 0)  / 10.0     （10~20 dB → 0~1）
      mod_score   = max(mod_depth - 1.2, 0) / 0.4  （1.2~1.6 → 0~1）
      harm_score  = max(harmonic_ratio - 0.5, 0) / 0.4  （0.5~0.9 → 0~1）
      phase_score = max(phase_cons - 0.5, 0) / 0.4      （0.5~0.9 → 0~1）
      cep_score   = max(cepstrum_s - 0.6, 0) / 0.4      （0.6~1.0 → 0~1）

    小于基线的值被截断为 0（视为正常骑行的波动），只有显著超过
    基线的值才贡献异常分。这相当于一个高通滤波器——滤除正常背景，
    仅保留异常信号。

    **11b — 加权融合。**

      anomaly_score = 0.35×snr_score + 0.25×mod_score
                    + 0.10×harm_score + 0.10×phase_score
                    + 0.20×cep_score

    权重设计的逻辑：
      · SNR（0.35）和调制深度（0.25）是核心——直接度量"是否存在
        强烈的周期调制"，合计占 60%。
      · Cepstrum（0.20）作为独立通道的交叉验证。
      · 谐波和相位（各 0.10）是辅助证据，单独存在不足以判定异响
        （正常骑行也可能偶然出现谐波或相位对齐）。

  Step 12 — 分段评分。

    异常得分通过以下分段函数映射为 0~100 的健康评分：

      anomaly < 0.25:         score = 100
      0.25 ≤ anomaly < 0.50:  score = 100 - 25×(anomaly - 0.25)/0.25
      0.50 ≤ anomaly < 0.70:  score = 70 - 40×(anomaly - 0.50)/0.20
      anomaly ≥ 0.70:         score = max(0, 30 - 30×(anomaly - 0.70)/0.30)

    分级语义：
      · <0.25 区间 → 100 分：基本无周期冲击，判定为"良好"。
      · 0.25~0.50 区间 → 100→70 分：轻微周期性成分，坡度 25 分/0.25
        异常（相对平缓），对应正常骑行中偶然出现的周期模式。
      · 0.50~0.70 区间 → 70→30 分：中等到明显周期性，判为"轻微"。
      · ≥0.70 区间 → 30→0 分：强烈周期性冲击，判为"异响"。

    评分 ≥ 70 为"良好"，40~69 为"轻微"，<40 为"异响"。



7.4  核心特征 vs 辅助特征
================================================================

表 7-1 总结了各特征在区分链条异响与环境噪音方面的能力差异。

表 7-1  特征区分能力对比

  ┌──────────────┬──────────┬──────────┬──────────┬──────────┐
  │ 特征          │ 链条异响  │ 风噪     │ 车流     │ 人声     │
  ├──────────────┼──────────┼──────────┼──────────┼──────────┤
  │ 包络谱 SNR    │ 高(>10dB)│ 低(<3dB) │ 低       │ 无       │
  │ 调制深度      │ 高(>1.2) │ 中(0.5~1)│ 中       │ 变化     │
  │ 谐波存在      │ 是       │ 否       │ 否       │ 否       │
  │ 相位一致性    │ 高(R>0.6)│ 低(R<0.3)│ 低       │ 低       │
  │ Cepstrum     │ 高(>0.6) │ 低(<0.2) │ 低       │ 低       │
  │ 高频能量比    │ 中~高    │ 低~中    │ 高       │ 变化     │
  │ 峰值因子      │ 高(>20)  │ 中(10~15)│ 中~高    │ 变化     │
  └──────────────┴──────────┴──────────┴──────────┴──────────┘

风噪和车流的共同特征是"缺乏稳定的周期性"。风噪是宽带随机噪声，车流
是非平稳噪声（其峰值间隔由车流密度决定而非踏频）。人声虽然可能在
元音段呈现谐波结构，但其基频（80~300 Hz）远低于踏频且不锁定于
任何稳定周期。

因此，五特征联合投票的误报率在理论上极低——要同时欺骗包络谱、倒谱、
谐波和相位四个通道，环境噪音需要恰好具备与骑行者踏频完全一致的
周期性调制结构，这在物理上几乎不可能发生。



7.5  实验验证
================================================================

利用三组真实骑行数据进行验证。三组数据均由已知链条状态良好（无干磨、
无异响）的单车采集，因此 F2 的理想输出应为 90~100 分。

表 7-2  三组数据集的 F2 检测结果

  ┌──────┬──────────┬──────────┬──────────┬──────────┬──────────┐
  │ 数据集│ SNR(dB)  │ 调制深度  │ 谐波比    │ 相位一致  │ 评分     │
  ├──────┼──────────┼──────────┼──────────┼──────────┼──────────┤
  │ (3)  │ 6.7      │ —        │ —        │ —        │ 95.5     │
  │ (6)  │ 11.7     │ —        │ 0.67     │ 0.21     │ 94.8     │
  │ (2)  │ 7.9      │ —        │ 0.67     │ —        │ 92.4     │
  └──────┴──────────┴──────────┴──────────┴──────────┴──────────┘

三组数据的 F2 评分均在 92~96 区间，与"链条正常"的已知状态一致。

  · 数据集 (3)：SNR=6.7 dB，低于 10 dB 基线，snr_score=0。其他特征
    也处于正常范围，anomaly≈0.29。该骑行路段可能是路面较平滑、踏频
    均匀的低噪声环境。

  · 数据集 (6)：SNR=11.7 dB，超过 10 dB 基线，snr_score≈0.17。但
    相位一致性仅 0.21（远低于 0.5 基线），phase_score=0。谐波比 0.67
    超出 0.5 基线，harm_score≈0.43。综合 anomaly≈0.30，处于良好区间。

  · 数据集 (2)：SNR=7.9 dB 低于基线，与 (6) 同为正常判定。

需要指出的是，当前三组数据均在气温适中、风力较小的条件下采集。在大风
天气下，风噪可能显著抬高 SNR 基线（麦克风风压也在低频产生周期调制）并
推高高频能量比。若未来发现大风场景评分异常降低，可通过提高 SNR 基线
（例如 10 dB → 12 dB）来补偿。



7.6  本章小结
================================================================

  (1) F2 基于包络谱-倒谱双通道联合验证策略，在无需任何标注训练数据的
      前提下实现了链条周期性冲击与环境随机噪声的有效区分。

  (2) 包络谱（希尔伯特变换 + 包络 FFT）从调幅角度检测踏频周期调制；
      倒谱从功率谱的频谱中检测周期性结构。两者独立验证同一物理现象，
      同时被欺骗的概率极低。

  (3) 基线偏移校准机制是评分合理性的关键——正常骑行天然的踏频调制
      不应贡献异常分。五个特征各自设定了"正常底线"，仅超出底线的
      部分计入异常分。

  (4) 五特征加权融合（SNR 0.35 + 调制深度 0.25 + Cepstrum 0.20
      + 谐波 0.10 + 相位 0.10）+ 分段评分函数，为正常车留出了
      0.25~0.50 的缓冲区间，三组正常车的评分稳定在 92~96 分。
