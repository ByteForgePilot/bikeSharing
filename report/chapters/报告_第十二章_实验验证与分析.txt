================================================================
    共享单车多传感器数据采集与健康检测系统

    第十二章  实验验证与分析
================================================================



12.1  实验数据集
================================================================

实验使用了三组独立的骑行采集数据，每组数据均由 BicycleDataLogger
Android App 在实际骑行中同步采集。三辆受测单车的基本信息如下：

  ┌──────┬──────────┬──────────────┬────────────────────────┐
  │ 数据集│ 采集时长  │ 数据量        │ 车况描述               │
  ├──────┼──────────┼──────────────┼────────────────────────┤
  │ (3)  │ ~62 s    │ 约 7,400 条   │ 车况良好，平整路面骑行   │
  │      │          │ 加 580K 音频  │ 轮胎正常，链条润滑良好   │
  ├──────┼──────────┼──────────────┼────────────────────────┤
  │ (6)  │ ~52 s    │ 约 6,200 条   │ 轻微偏摆，全程颠簸路面   │
  │      │          │ 加 493K 音频  │ 轮胎存在可感偏摆         │
  ├──────┼──────────┼──────────────┼────────────────────────┤
  │ (2)  │ ~56 s    │ 约 6,700 条   │ 偏摆较明显，全程颠簸路面 │
  │      │          │ 加 532K 音频  │ 轮胎偏摆量高于 (6)        │
  └──────┴──────────┴──────────────┴────────────────────────┘

三组数据均经窗口选取算法处理（原始时长 >30 秒触发自适应裁剪）。



12.2  F1 轮胎偏摆检测验证
================================================================

12.2.1  定量结果

表 12-1  三组数据 F1 检测结果对比

  ┌──────┬──────────┬──────────┬──────────┬──────────────┬──────────┐
  │ 数据集│ 轮频(Hz) │ A1       │ A2       │ P            │ F1 评分   │
  ├──────┼──────────┼──────────┼──────────┼──────────────┼──────────┤
  │ (3)  │ 4.7      │ 0.1043   │ 0.2472   │ 0.2279       │ 100.0    │
  │ (6)  │ 6.4      │ 0.3083   │ 0.2798   │ 0.4482       │ 80.0*    │
  │ (2)  │ 7.5      │ 0.5125   │ 0.3383   │ 0.6816       │ 71.2     │
  └──────┴──────────┴──────────┴──────────┴──────────────┴──────────┘
  * 原始评分 91.5，因 flat_fraction=0% 触发平整惩罚限至 80.0。

12.2.2  分析

  (A) P 值梯度与车况一致。

      (3) 的 P=0.23 低于 P_normal(0.35)，满分。该车的轮胎振动信号
      在频谱中无明显的轮频周期峰，Z 轴加速度主要由路面随机激励主导。
      A1=0.10、A2=0.25 的量级与正常轮胎的基准值高度吻合。

      (6) 的 P=0.45 已超过 P_normal 线，A1 升至 0.31——轮频处
      的振动幅值约为正常车的 3 倍。该车经人工目视检查确认轮圈存在
      可感知的偏摆变形。

      (2) 的 P=0.68 是 (6) 的 1.5 倍、(3) 的 3 倍。A1=0.51 达到
      正常基准的 5 倍水平，表明每转一圈的冲击能量极为突出。该车
      的偏摆程度为三组中最重。

  (B) 平整路面惩罚的必要性。

      (6) 和 (2) 的 flat_fraction 均为 0%，意味着全程无平整路段。
      在颠簸路面上，FFT 频谱中的轮频峰值可能部分来源于路面激励
      而非纯粹的偏摆振动。算法通过 80 分上限表达"检测结果置信度
      有限"的语义，是保守与合理之间的恰当折中。

  (C) 轮频估计的偏差分析。

      (6) 和 (2) 的轮频估计值（6.4 Hz 和 7.5 Hz）对应车速约 50~60
      km/h，与共享单车的实际速度范围不符。可能原因是 FFT 在
      颠簸路面上将 2f 倍频误判为基频，或将路面共振峰误判为轮频。
      不过，由于评分同时考察 f 和 2f 两处幅值，即使基频估计偏高
      一倍（实际轮频约 3.2~3.8 Hz），其在 2f 位置（6.4~7.5 Hz）
      同样会被提取——A2 依然反映了偏摆的信息。换言之，轮频估计的
      绝对值偏差不显著影响 P 值的相对排序。



12.3  F2 链条异响检测验证
================================================================

12.3.1  定量结果

表 12-2  三组数据 F2 检测结果对比

  ┌──────┬──────────┬──────────────┬──────────┬──────────┬──────────┐
  │ 数据集│ SNR(dB)  │ 谐波比        │ 相位一致  │ anomaly  │ F2 评分   │
  ├──────┼──────────┼──────────────┼──────────┼──────────┼──────────┤
  │ (3)  │ 6.7      │ —            │ —        │ 0.29     │ 95.5     │
  │ (6)  │ 11.7     │ 0.667        │ 0.214    │ 0.30     │ 94.8     │
  │ (2)  │ 7.9      │ 0.667        │ —        │ 0.33     │ 92.4     │
  └──────┴──────────┴──────────────┴──────────┴──────────┴──────────┘

12.3.2  分析

  (A) 三组数据评分均在 92~96 区间，与实际链条状态（均良好）一致。
      基线偏移校准机制成功屏蔽了正常骑行固有的踏频调制——尽管
      三组数据的 SNR 分别达到 6.7、11.7 和 7.9 dB，但在减去 10 dB
      正常基线后，(3) 和 (2) 的 snr_score 归零，仅 (6) 因 SNR
      略超基线而产生了少量异常分。

  (B) (6) 的 SNR 偏高（11.7 dB vs 其他两组的 7~8 dB）可能与环境
      有关。该组数据的骑行路线全程颠簸（F1 flat=0%），路面不规则
      冲击在 2~4 kHz 频带产生额外的能量调制。这解释了为何 (6) 的
      anomaly（0.30）略高于 (3)（0.29）——路面的随机冲击虽然不锁定
      踏频相位（相位一致性仅 0.21 < 0.5 基线），但确实抬升了包络谱
      的整体噪声底，使 SNR 出现反常偏高。

      **改进方向**：可将 flat_fraction（来自 F1）作为 F2 的辅助
      修正因子传入——颠簸路面上适度降低 SNR 的权重，或提高 SNR
      基线。当前版本尚未实现这一跨检测器的信息共享。

  (C) 键性指标间无虚假高相关。(6) 的谐波比 0.667 属三组最高，
      但其相位一致性仅 0.214（三组最低）。这两个特征的方向一致
      性——真正的链条异响应同时具有高 SNR、高谐波和高相位一致性
      ——当前数据中未出现。三组数据的评分均落在"良好"区间，说明
      特征融合的误报控制有效。



12.4  F3 车头不正检测验证
================================================================

12.4.1  定量结果

表 12-3  三组数据 F3 检测结果对比

  ┌──────┬──────────┬──────────────┬──────────┬──────────┐
  │ 数据集│ Δθ (°)   │ 直行段数       │ 方法      │ F3 评分   │
  ├──────┼──────────┼──────────────┼──────────┼──────────┤
  │ (3)  │ 3.18     │ —            │ IMU-only │ 100.0    │
  │ (6)  │ 5.11     │ 13           │ IMU-only │ 81.5     │
  │ (2)  │ 4.38     │ —            │ IMU-only │ 93.7     │
  └──────┴──────────┴──────────────┴──────────┴──────────┘

12.4.2  分析

  (A) (3) 的 Δθ=3.18° < θ_ok(4°)，满分。该车车把与前轮的对中度
      在正常装配公差内。

  (B) (6) 的 Δθ=5.11° 位于 4°~10° 线性衰减区的中段。该车可能存
      在轻微的安装偏差，虽然骑行者主观感受"有点别扭但不明显"，
      但算法已检测到 13 个直行段的偏置一致性足以给出 81.5 的评分。

  (C) (2) 的 Δθ=4.38°，恰好略超 4° 线。93.7 分表示极其轻微的
      偏斜——运维人员若非专门测量可能根本不会察觉。这说明 4° 的
      满分线在当前数据上起到了恰当的筛选效果。

  (D) 三组数据均未触发 wobble 惩罚（Δθ 均 > GYRO_SILENT_GATE=3°），
      也未触发 sign_consistency 增强。v3.2 新增的加速度计辅助机制
      在三组实验数据上未表现出差异化的贡献，但这不意味着它是多余的
      ——它相当于一个仅在边界条件下启用的安全网。



12.5  综合评分验证
================================================================

表 12-4  三组数据最终评分对比

  ┌──────┬──────┬──────┬──────┬────────┬────────┬──────────┐
  │ 数据集│ F1   │ F2   │ F3   │ H      │ 综合 S  │ 建议     │
  ├──────┼──────┼──────┼──────┼────────┼────────┼──────────┤
  │ (3)  │ 100.0│ 95.5 │ 100.0│ 98.6   │ 98.6   │ 推荐骑行  │
  │ (6)  │ 80.0 │ 94.8 │ 81.5 │ 84.4   │ 72.2   │ 谨慎使用  │
  │ (2)  │ 71.2 │ 92.4 │ 93.7 │ 82.8   │ 65.3   │ 谨慎使用  │
  └──────┴──────┴──────┴──────┴────────┴────────┴──────────┘

12.5.1  排序合理性

  三组数据的综合评分排序为 (3) > (6) > (2)，其中 (3) 以大幅领先
  （98.6 vs 72.2）与其余两组形成明显分界。这与"一辆完美车 +
  两辆有不同程度短板的单车"的实际情况吻合。

12.5.2  木桶效应验证

  (6) 和 (2) 的 F2 几乎相等（94.8 ≈ 92.4），F3 差距也不大（81.5
  vs 93.7），合并考虑似乎 (2) 更好。但 F1 的差距（80.0 vs 71.2）
  通过木桶机制拉大了综合分的差异——(6) 比 (2) 高 6.9 分。如果
  改为算术平均，(2) 的总分（85.8）甚至会超过 (6)（85.4），导致
  排序反转。这验证了章节 9.1 中关于"算术平均可能误导"的论断。

12.5.3  评分分布

  三组评分覆盖了 good→caution 的边界（98.6 → 72.2 → 65.3），
  分布跨度约 33 分。目前尚缺少应进入 bad 区间的数据（如严重偏摆+
  链条异响+车头歪斜同时存在的极端单车），建议在后续的数据收集中
  刻意加入此类边缘样本以验证评分公式在全谱系上的单调性。



12.6  窗口选取算法验证
================================================================

三组数据均触发了自适应窗口选取——原始时长（52~62 秒）超过了 30
秒阈值，算法从未裁剪的全程数据中选取了 15 秒的最优分析窗口。

  ┌──────┬──────────┬──────────────┬──────────────┐
  │ 数据集│ 原始时长  │ 窗口内加速度计数│ 窗口内音频采样│
  ├──────┼──────────┼──────────────┼──────────────┤
  │ (3)  │ ~62 s    │ —            │ —            │
  │ (6)  │ ~52 s    │ 1,498        │ 120,640      │
  │ (2)  │ ~56 s    │ —            │ —            │
  └──────┴──────────┴──────────────┴──────────────┘

从 6,185 条原始加速度计数据中选取了 1,498 条作为最优窗口——约缩减
至 24%。选取的窗口在 az 方差最小和 gz 方差最低的双重标准下，代表了
该次骑行中路面最平整、骑姿最直且速度最平稳的 15 秒片段。算法耗时
方面，窗口选取本身（向量化滑动窗口 + argmin）约需 0.3~0.5 秒，
在总处理时间中占比可忽略。



12.7  局限性
================================================================

基于三组实验数据的分析，识别出以下当前版本的局限性：

  (1) 缺少 Bad 区间的验证样本。三组数据的最差综合分为 65.3
      （caution），尚未覆盖 <50 分（建议换车）的区间。算法的
      全谱系单调性仅在高分段得到验证。

  (2) 环境条件单一。所有数据均在气温适中、风力较小的白天采集，
      未覆盖大风（对 F2 风噪干扰）、雨天（胎噪变化）、夜间
      （GPS 信号可能更差）等工况。

  (3) 手机型号单一。所有数据使用同一台 Android 手机采集，传感器
      的跨设备差异性未被验证。

  (4) 无独立标定数据。F1 的 P_normal、F3 的 θ_ok 等阈值通过
      有限样本的反复试错确定，而非通过更大规模的统计分布分析。



12.8  本章小结
================================================================

  (1) 三个检测器在三组数据上均表现出与车况一致的评分梯度——F1 从
      100 降至 71（轮胎从完美到偏摆），F2 稳定在 92~96（链条均正常），
      F3 从 100 降至 82（车头从对中到轻微偏斜）。

  (2) 综合评分通过木桶效应成功区分了三辆车——完美车 99 分、中等车
      72 分、短板车 65 分。

  (3) 当前验证集的覆盖范围仍有不足（缺 <50 分样本、缺恶劣环境数据、
      单设备），建议后续扩充测试数据的多样性和极端性。
