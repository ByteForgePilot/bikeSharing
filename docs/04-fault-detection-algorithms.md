# 04 -- 故障检测算法 v3.0

## 概述

共享单车健康检测系统使用手机内置传感器（加速度计、陀螺仪、麦克风）进行三级故障检测：

| 检测项 | 传感器 | 核心方法 | 输入 |
|--------|--------|----------|------|
| F1 轮胎偏摆 | 加速度计 Z 轴 | FFT + 车轮转频估计 | 100Hz 加速度计数据 |
| F2 链条异响 | 麦克风 | 包络谱分析 + Cepstrum | 8kHz 16-bit PCM 音频 |
| F3 车头不正 | 陀螺仪 Z 轴 | 直行段选择 + 偏航偏置 | 50Hz 陀螺仪数据 |

## F1 -- 轮胎偏摆检测

### 原理

轮胎偏摆产生与车轮转频同步的周期性振动，通过 FFT 提取车轮转频 f 及二次谐波 2f 的幅值。

### 算法流程

1. Z 轴加速度去直流 → 重采样到 100Hz → Butterworth 带通滤波(2~40Hz)
2. 滑动窗口方差判定平整路面（1s 窗口，阈值 0.5）
3. 优先使用平整路面片段；若不足 20% 则降级使用全部数据
4. 车轮转频估计：有 GPS 时 `f = v/(2πr)`, r=0.35m，在期望频率 ±2Hz 搜索；无 GPS 时全范围 1.5~8Hz
5. FFT 归一化幅值，提取 `A1 = 幅值@f`, `A2 = 幅值@2f`
6. 偏摆特征值 `P = A1 + 0.5*A2`
7. 线性插值评分：P ≤ 0.15 → 100 分，P ≥ 0.60 → 0 分，中间线性

**阈值标定**：P_healthy=0.15（正常轮胎仅路面随机激励），P_severe=0.60（辐条松动/轮圈变形的显著周期振动）

## F2 -- 链条异响检测

### 原理

采用**零训练数据的包络谱分析**方案。核心思想：链条异响 = 与踏频同步的周期性金属冲击，而风噪/车流/人声无此特征。

### 算法流程

1. 音频重采样到 8kHz
2. 踏频估计（未提供时自相关法估算 1~5Hz 范围）
3. 带通滤波 2~4kHz（链条冲击共振频带）→ 希尔伯特变换提取包络
4. 低通滤波 0.5~10Hz（仅保留踏频范围）
5. **包络谱 SNR**：FFT 包络 → 踏频处峰值与噪声基底的 dB 比
6. **谐波检测**：检测是否存在 2×/3× 踏频谐波
7. **相位一致性**：峰-峰间隔的圆形方差（链条在固定曲柄相位冲击）
8. **Cepstrum 周期特征**：倒谱中踏频对应 quefrency 处的 SNR
9. 四特征融合：`envelope_score = 0.35*snr + 0.25*harm + 0.20*phase + 0.20*cepstrum`
10. 辅助特征：高频能量比(2~4kHz) + 峰值因子
11. 综合异常分 = 0.60*核心 + 0.40*辅助 → 线性评分

### 为什么能区分链条异响 vs 环境噪音

| 特征 | 链条异响 | 风噪/车流 | 人声 |
|------|:---:|:---:|:---:|
| 包络谱 SNR @ 踏频 | **高** (>8dB) | 低 | 无 |
| 谐波存在 (2f, 3f) | **是** | 否 | 否 |
| 冲击相位一致性 | **高** (R>0.6) | 低 (R<0.3) | 低 |
| 高频能量比 | 中-高 | 高 | 变化 |

## F3 -- 车头不正检测

### 原理

车头偏斜 → 骑行时为维持直行需持续施加补偿力矩 → 陀螺仪 Z 轴出现非零偏置。

### 算法流程 (无 GPS 适配版)

1. 陀螺仪 Z 轴重采样到 50Hz
2. 滑动窗口扫描，取 gz 方差最低的 30% 窗口作为"准直行段"
3. 绝对质量门槛：最佳段 gz_std < 0.3 rad/s (\~17 deg/s)，否则判定无有效直行段
4. 各最佳段计算 gz 均值和累计偏航角
5. 等效车头偏角：`delta_theta = 0.7 * |gz_bias|*2s + 0.3 * avg(|yaw_deviation|)`
6. 线性评分：Δθ ≤ 5 deg → 100 分，Δθ ≥ 15 deg → 0 分

## 综合健康评分（木桶效应）

```
H = 1 / (0.4/F1 + 0.3/F2 + 0.3/F3)    -- 加权调和平均
penalty = min(F1, F2, F3) / 100        -- 最小值惩罚因子
S = H * penalty                        -- 最终评分 (0~100)
```

**设计意图**：使用调和平均 + 最小值惩罚确保某项严重故障不被其他高分项掩盖。一只轮胎偏摆严重的车即使链条和车把正常，综合评分也是不及格的。

### 评分分级

| S 范围 | 等级 | 建议 |
|--------|------|------|
| >= 70 | good | 推荐骑行 |
| 50-69 | caution | 谨慎使用 |
| < 50 | bad | 建议换车 |

## 大数据自适应窗口

对于长时间骑行数据（>30s 传感器或 >30s 音频），自动选取骑行质量最高的 15s 窗口：
- 加速度计 Z 轴方差低 → 路面平整
- 陀螺仪 Z 轴方差低 → 骑行直
- 向量化滑动窗口扫描，O(n) 复杂度
- 按时间戳对应裁剪音频数据
