# 传感器数据采集指南

## 手机放置方式

为了获得可靠的检测结果，请按照以下方式放置手机：

### 轮胎偏摆检测
- 将手机固定在车把或车架固定位置
- 确保手机稳定不晃动
- 加速度计 Z 轴对准上下方向，X 轴对准左右方向

### 链条异响检测
- 手机麦克风朝向链条方向
- 距离链条约 30-50cm
- 避免风噪干扰（可用防风罩或放在口袋内）

### 车头不正检测
- 手机固定在车把正中位置
- 屏幕朝上，USB 口朝前
- 陀螺仪 Z 轴对准垂直方向

## 骑行要求

1. **预热阶段** (10秒): 上车后静置手机，记录静止基准值
2. **直行骑行** (至少30秒): 保持直线骑行，用于车头不正检测
3. **正常骑行** (建议5分钟以上): 包含匀速、加速、减速，覆盖多种工况

## 采样配置

| 参数 | 值 | 说明 |
|------|-----|------|
| 加速度计量程 | ±16g | 覆盖正常骑行振动 |
| 加速度计采样率 | 50 Hz | 满足奈奎斯特定理 (最高检测5Hz) |
| 陀螺仪量程 | ±2000°/s | 覆盖转向和振动 |
| 陀螺仪采样率 | 50 Hz | 对齐加速度计 |
| 音频采样率 | 44100 Hz | CD 音质，覆盖 2-8kHz 异响 |
| 音频格式 | PCM 16-bit | 单声道 |

## 数据质量检查

上传前自动检查：
- 传感器数据连续性（时间戳间隔检查）
- 加速度范围合理性（不超量程）
- 音频静音检测（避免录制空文件）
