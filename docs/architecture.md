## 数据流

1. **骑行开始** — 用户输入车辆编号 → 后端创建骑行记录
2. **传感器采集** — 手机 20Hz 采样加速度计+陀螺仪，44.1kHz 采样麦克风
3. **数据上传** — 每 100 条样本批量上传传感器数据
4. **故障分析** — 骑行结束后触发异步分析
   - 轮胎偏摆: FFT 频谱分析 (1-5Hz)
   - 链条异响: MFCC + 异常检测 (2-8kHz)
   - 车头不正: 偏航角均值分析
5. **结果展示** — 综合报告返回移动端，展示检测结果

## 关键决策

- 传感器采样率 20Hz 足够捕获轮圈周期性振动（最高 5Hz），同时节省电量
- 音频录制使用手机内置麦克风，44.1kHz CD 音质足够检测高频链条噪声
- 批量上传减少网络请求次数和电池消耗
- 故障检测在服务端完成，支持模型迭代升级
