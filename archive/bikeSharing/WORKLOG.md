## 2026-05-20 15:30 | v3.0 F2 升级为包络谱分析方案

**动机**：用户质疑"如何区分链条异响和环境噪音"

**v2 局限**：四维启发式特征只能判断"声音是否异常"，无法区分链条故障 vs 风噪/车流

**v3 方案**：零训练数据的包络谱分析 (Envelope Spectrum Analysis)

**原理**：
```
链条异响 = 与踏频同步的周期性金属冲击
环境噪音 = 无此周期性特征

8kHz音频 → 带通2~4kHz(链条共振带) → 希尔伯特包络 → 低通0.5~10Hz
→ FFT包络谱 → 踏频SNR + 谐波检测 + 相位一致性 → 综合打分
```

**新增函数**：
- `_hilbert_envelope()` — 希尔伯特变换提取包络
- `_envelope_spectrum_snr()` — 目标频率处包络谱 SNR
- `_check_harmonics()` — 检测 2×/3× 踏频谐波
- `_phase_consistency()` — 冲击间隔的圆形方差分析

**评分权重**：
- 核心（0.55）：包络谱 SNR @ 踏频 (0.45) + 谐波比 (0.30) + 相位一致性 (0.25)
- 辅助（0.45）：高频能量比 (0.55) + 峰值因子 (0.45)

**关联修改**：
- `main()`: `f1['wheel_freq_hz']` 作为踏频传入 F2
- `web_server.py`: 同上
- `templates/index.html`: F2 面板更新字段 (SNR, 谐波比, 相位一致性)
