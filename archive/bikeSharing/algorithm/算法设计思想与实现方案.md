                                         │

## 2. F1 轮胎偏摆检测

### 2.1 物理原理

轮胎偏摆时，轮辋存在固定形变。每转一圈，形变处拍打地面一次，在车身 Z 轴方向产生一个**与轮速同步的周期性振动**。正常轮胎只有随机路面激励，无此周期分量。

```
正常轮胎:  Z轴振动 = 路面随机噪声 (白谱)
偏摆轮胎:  Z轴振动 = 路面噪声 + f·A₁·sin(2πft) + 2f·A₂·sin(4πft)
```

其中 `f` 为车轮旋转频率，`A₁` 为轮频幅值，`A₂` 为二倍频幅值。

### 2.2 数据流

```
加速度计 Z 轴 → 去直流 → 100Hz 重采样 → 2~40Hz 带通 → 平整路面筛选 → FFT
                                                                          │
                                                            ┌─────────────┘
                                                            ▼
                                            轮频 f = argmax(|FFT|), f∈[1.5,8]Hz
                                                            │
                                                            ▼
                                            提取 A₁(f) 和 A₂(2f)
                                                            │
                                                            ▼
                                            P = A₁ + 0.5×A₂
                                                            │
                                                            ▼
                                            P≤0.15→100分, P≥0.60→0分, 线性插值
```

### 2.3 关键设计决策

#### 2.3.1 平整路面筛选

不是所有路面都适合检测。鹅卵石路、减速带等会产生远大于轮胎偏摆的振动，掩盖故障信号。

**方案**: 1 秒滑动窗口，计算 Z 轴加速度方差。方差 < 0.5 m²/s⁴ 判定为"平整路面"。

```
窗口内方差 = Var(az_filtered[i : i+window])
平整判定: 方差 < 0.5
平整占比: flat_fraction = 平整窗口数 / 总窗口数
```

- 平整占比 ≥ 20%: 仅使用平整窗口拼接信号进行 FFT
- 平整占比 < 20%: 使用全部信号，但可信度降低
- 平整占比 < 30%: 评分上限 75 分（非平整路面置信度低）

#### 2.3.2 轮频估计

方法一 (有 GPS 车速，**新增优化**):

```
f_expected = v / (2πr)     # r = 0.35m, 共享单车轮胎半径
搜索范围 = [f_expected - 1Hz, f_expected + 1Hz]  # 缩小搜索窗
```

方法二 (无 GPS，默认): 在 1.5~8Hz（对应 6~30 km/h）FFT 频谱中取最大峰值。

#### 2.3.3 P 值计算与评分

```
归一化 FFT 幅值: mag = |FFT| / (N/2)    # N = 信号长度
A₁ = max(mag[f - 0.3Hz : f + 0.3Hz])    # 轮频处幅值
A₂ = max(mag[2f - 0.3Hz : 2f + 0.3Hz])  # 二倍频处幅值
P = A₁ + 0.5 × A₂                        # 偏摆特征值

评分映射 (0~100):
  P ≤ 0.15  → 100   (正常，仅有随机路面激励)
  P ≥ 0.60  →   0   (严重偏摆，显著周期振动)
  之间      → 线性插值
```

#### 2.3.4 参数来源

| 参数 | 值 | 来源 |
|------|-----|------|
| WHEEL_RADIUS | 0.35 m | 共享单车 26 寸轮径 |
| 频率搜索范围 | 1.5~8 Hz | 对应 6~30 km/h 车速 |
| 平整方差阈值 | 0.5 m²/s⁴ | 经验标定 (多路段实测) |
| P_healthy | 0.15 | 正样本 FFT 幅值统计 |
| P_severe | 0.60 | 故障样本 FFT 幅值统计 |
| FFT 归一化 | ÷ (N/2) | 统一不同时长信号的幅值量纲 |

## 3. F2 链条异响检测

### 3.1 物理原理

链条异响的本质是**与踏频同步的周期性金属冲击**，这是区分故障声与环境噪音的关键：

```
链条异响: 周期性冲击 → 包络谱在踏频处有尖锐峰 + 谐波结构 + 相位锁定
风噪:     宽带随机   → 包络谱平坦, 无谐波, 无相位结构
车流噪音: 偶发冲击   → 虽有冲击但无固定周期
人声:     频率调制   → 包络变化缓慢, 无 1~5Hz 周期
```

核心洞察：**不是分析声音本身，而是分析声音包络的周期性**。环境噪音无论多大，只要不是与踏频锁相的周期性冲击，就不会在包络谱产生峰值。

### 3.2 数据流

```
PCM 音频 (16-bit) → 归一化 float32 [-1,1] → 8kHz 重采样
                                                   │
                                    ┌──────────────┘
                                    ▼
                        踏频估计 (自相关法)
                        │            ┌──────────────────┐
                        │            │ 无外部踏频输入时:  │
                        │            │ 包络→低通→自相关   │
                        │            │ 基频 = 1/峰值延迟  │
                        │            └──────────────────┘
                        ▼
            2~4kHz 带通滤波 (链条金属冲击共振频带)
                        │
                        ▼
            希尔伯特变换 → 解析信号 → |·| → 包络信号
                        │
                        ▼
            0.5~10Hz 低通滤波 (仅保留踏频范围)
                        │
          ┌─────────────┼─────────────┐
          ▼             ▼             ▼
    包络谱 SNR      谐波检测      相位一致性
    @ 踏频         2×/3× 谐波    圆形方差 R
          │             │             │
          └─────────────┼─────────────┘
                        │
                        ▼
              辅助特征: 高频能量比 + 峰值因子
                        │
                        ▼
              多特征融合 → 异常得分 → 正常/异响 → 评分
```

### 3.3 关键设计决策

#### 3.3.1 频率域筛选: 2~4kHz 带通

链条金属冲击的共振能量集中在 2~4kHz。4 阶 Butterworth 带通滤波器直接切除低频风噪（<1kHz）和极高频电噪（>8kHz）。

```
filtered = butter_bandpass(audio_8k, [2000, 4000], order=4)
```

#### 3.3.2 包络提取: 希尔伯特变换

```python
analytic = hilbert(filtered)       # 解析信号
envelope = |analytic|              # 瞬时幅值包络
envelope_lp = lowpass(envelope, 10Hz)  # 仅保留踏频范围 (0.5~10Hz)
```

希尔伯特包络提取的是"声音有多响"的慢变信息。低通 10Hz 是关键——去除了载波频率（2~4kHz），仅保留幅值调制（踏频范围）。

#### 3.3.3 踏频估计 (自相关法, v3.1 优化)

原始 v2 方案在包络谱中扫描 1~5Hz 最强峰值——当路面有周期性激励时可能误判。v3.1 改为自相关法：

```python
ac = correlate(envelope_lp, envelope_lp)   # 自相关
ac = ac[len(ac)//2:]                       # 取正延迟
# 在 0.2~1.0s 延迟范围内找第一个显著峰
# pedal_freq = 1 / lag_at_peak
```

自相关对周期信号的敏感度比 FFT 峰值扫描更鲁棒——即使包络谱峰不明显，自相关仍能捕捉周期性。

#### 3.3.4 包络谱 SNR 分析

对低通包络做 FFT，在踏频处测量信噪比：

```python
peak_val = max(|FFT(envelope)|[pedal_freq - 0.3 : pedal_freq + 0.3])
noise_floor = median(|FFT(envelope)|[0.3~15Hz, 排除踏频及谐波])
SNR_dB = 20 * log10(peak_val / noise_floor)
```

| SNR | 含义 |
|-----|------|
| < 3 dB | 无周期冲击，环境噪音 |
| 3~8 dB | 模糊区 |
| > 8 dB | 明显踏频同步冲击，强烈指示链条异响 |

#### 3.3.5 谐波检测

链条冲击产生丰富谐波。检查 2×、3× 踏频处是否存在超过噪声基底 2 倍（>6dB）的峰值：

```python
harmonic_ratio = detected_harmonics / n_harmonics  # ∈ [0, 1]
```

正常链条也可能有微弱基频振动，但不会有完整谐波族。

#### 3.3.6 冲击相位一致性 (圆形方差)

这是**区分链条异响和环境噪音最核心的特征**：

```
链条异响: 每次冲击都发生在曲柄的固定相位
         → 包络峰值间隔 ≈ n × 踏频周期
         → 间隔 mod 周期 = 常数相位
         → 圆形方差 R ≈ 1

环境噪音: 冲击随机发生
         → 包络峰值间隔无规律
         → 相位分散
         → 圆形方差 R ≈ 0
```

```python
peaks = find_peaks(envelope_lp)        # 检测包络峰值
intervals = diff(peaks) / fs           # 峰-峰间隔 (秒)
phases = (intervals % period) / period # 等效曲柄相位 ∈ [0,1]
angles = phases × 2π                   # 转到角度
R = sqrt(mean(cos(angles))² + mean(sin(angles))²)  # 圆形方差
```

- R > 0.6: 冲击锁定在踏板相位 → 链条异响
- R < 0.3: 冲击相位随机 → 环境噪音

#### 3.3.7 多特征融合评分

v3.1 采用**五维加权融合**:

| 特征 | 类型 | 权重 | 物理含义 |
|------|------|------|---------|
| 包络谱 SNR @ 踏频 | 核心 | 0.35 | 踏频处有无周期能量 |
| 谐波比例 | 核心 | 0.25 | 是否存在丰富谐波族 |
| 相位一致性 R | 核心 | 0.20 | 冲击是否相位锁定 |
| cepstrum 得分 | 核心 | 0.20 | 倒谱域周期性确认 |
| 高频能量比 | 辅助 | 0.55 | 2~4kHz 能量占比 |
| 峰值因子 | 辅助 | 0.45 | 冲击强度相对 RMS |

综合异常得分:

```
anomaly_score = 0.65 × 核心得分 + 0.35 × 辅助得分
```

决策阈值:

```
anomaly_score < 0.25 → 正常 (置信度 ≥ 0.8 时评分 100)
anomaly_score > 0.55 → 异响 (置信度 ≥ 0.8 时评分 0)
中间区域 → 线性映射
```

### 3.4 为什么这套方案不需要训练数据

传统 ML 方案（如 v2 的四维特征 + SVM）需要标注数据才能区分"链条异响 vs 环境噪音"。包络谱方案利用的是**物理因果约束**：

- 环境噪音**不可能**在踏频处有稳定包络谱峰
- 环境噪音**不可能**有锁相的谐波族
- 只有链条的周期性金属撞击**才能**同时满足所有维度

所以这是一个**基于物理模型的零样本检测器**，不需要任何训练数据。

## 4. F3 车头不正检测

### 4.1 物理原理

车头偏斜时，前轮方向与车架中轴线存在一个固定偏角 Δθ。骑行时，为维持直线行驶，骑行者需持续施加补偿力矩 → 陀螺仪 Z 轴（偏航轴）出现**非零稳态偏置**。

```
正常车头: 直行时 gz ≈ 0 (无偏置), 转弯时 gz ≠ 0 但有去有回
偏斜车头: 直行时 gz ≈ bias ≠ 0 (持续补偿), 转弯时叠加在 bias 之上
```

关键在于找到"直行段"并测量其中的 gz 均值。

### 4.2 数据流

```
陀螺仪 Z 轴 (gz, rad/s) → 50Hz 重采样
                              │
                              ▼
                  5s 滑动窗口 → 每窗口 std(gz)
                              │
                              ▼
                  取方差最小的 30% 窗口 (准直行段)
                              │
                    ┌─────────┴─────────┐
                    ▼                   ▼
              绝对质量门槛            通过检查
         最直段 std > 0.3?              │
                    │                   ▼
                   是          每个准直行段计算:
                    │          ① gz 均值 (偏航偏置)
                    ▼          ② 累计偏航角 ∫gz·dt
          返回 "无法检测"
          (全程转弯)        ┌─────────┴─────────┐
                            ▼                   ▼
                      Δθ_bias = |gz_bias| × 2s  Δθ_yaw = mean(|累计偏航角|)
                      (偏置换算, 权重 0.7)      (漂移量, 权重 0.3)
                            │                   │
                            └─────────┬─────────┘
                                      ▼
                              Δθ = 0.7×Δθ_bias + 0.3×Δθ_yaw
                                      │
                                      ▼
                              Δθ≤5°→100分, Δθ≥15°→0分, 线性插值
```

### 4.3 关键设计决策

#### 4.3.1 直行段检测

```python
# 5 秒滑动窗口 (250 点 @ 50Hz), 步长 25% = 62 点 (75% 重叠)
for start in range(0, len(gz_uniform) - window_n, step_n):
    seg = gz_uniform[start : start + window_n]
    segments.append((std(seg), seg))     # std 越小 → 骑得越直

# 取标准差最小的 30%
segments.sort(key=lambda x: x[0])
best_segments = segments[:top_30%]
```

#### 4.3.2 绝对质量门槛 (v3.1 新增)

原始方案不管有没有直行段，都硬取前 30%。如果全程在转弯（如小区内部道路），这 30% 的"最直"段 gz std 仍然 > 0.3 rad/s (≈17°/s)，此时检测不可靠。

```python
if best_std > 0.3:      # rad/s
    return 100.0 分 + warning "无有效直行段，建议在平直路段重新检测"
```

#### 4.3.3 偏置换算为等效偏角

```python
Δθ_bias = |gz_bias| × T_obs     # T_obs = 2s (骑行者感知漂移的时间尺度)
                                 # gz_bias = 准直行段 gz 均值
Δθ_yaw  = mean(|累计偏航角|)     # 各准直行段的平均漂移量

Δθ = 0.7 × degrees(Δθ_bias) + 0.3 × degrees(Δθ_yaw)
```

`T_obs = 2s` 对应骑行者感知到车身偏离并开始纠正的反应时间窗口。2 秒内积累的偏航角偏差反映了车头偏斜的严重程度。

#### 4.3.4 评分映射

```
Δθ ≤ 5°   → 100 分 (正常车头，无感知偏斜)
5°<Δθ<15°  → 线性插值
Δθ ≥ 15°  → 0 分   (严重偏斜，骑行费力)
```

#### 4.3.5 设计局限

- 无 GPS 航向角作为 ground truth，依赖 gz 偏置的间接估计
- `T_obs=2s` 和 `0.7/0.3` 权重为启发式参数
- 有标注数据后可通过回归标定

## 5. 综合健康评分

### 5.1 设计思想: 木桶效应

传统的加权算术平均 `S = 0.4×F1 + 0.3×F2 + 0.3×F3` 存在致命缺陷:

```
示例: F1=100, F2=100, F3=5   → S = 0.4×100 + 0.3×100 + 0.3×5 = 71.5 → "推荐骑行"
```

车头偏 15° 的车居然"推荐骑行"，这显然不合理。**综合评分必须体现短板效应**。

### 5.2 双机制评分公式

```
H = 1 / (0.4/F1 + 0.3/F2 + 0.3/F3)          (1) 加权调和平均
penalty = min(F1, F2, F3) / 100              (2) 最小值惩罚因子
S = H × penalty                              (3) 最终评分
```

#### 机制 1: 加权调和平均

调和平均天然对低分敏感。同一组输入:

```
算术平均: (100, 100, 5)  → 71.5 (被高分拉上去了)
调和平均: 1/(0.4/100+0.3/100+0.3/5) = 1/(0.004+0.003+0.06) = 1/0.067 = 14.9
```

调和平均下，低分项的贡献主导分母，综合分被显著拉低。

#### 机制 2: 最小值惩罚

即使调和平均，如果所有分都偏低但均匀（如 F1=40, F2=40, F3=40），H=40，仍然偏高。最小值惩罚进一步压低:

```
penalty = 40/100 = 0.4
S = 40 × 0.4 = 16
```

这体现了"三项都差，比一项差更糟"的现实逻辑。

### 5.3 评分阈值

```
S ≥ 70 → "推荐骑行" (good)
50 ≤ S < 70 → "谨慎使用" (caution)
S < 50 → "建议换车" (bad)
```

### 5.4 权重设计

```
轮胎偏摆 (F1): 0.40  — 影响骑行安全和体力消耗最直接
链条异响 (F2): 0.30  — 噪音体验 + 链条寿命指示
车头不正 (F3): 0.30  — 操控性影响，但多数用户可适应轻微偏斜
```

## 6. 大数据自适应窗口选取

### 6.1 问题

用户可能录制数分钟的数据。全量 FFT 计算量大且包含大量冗余信息（重复的直行/匀速段）。需要在保证检测精度的前提下减少计算量。

### 6.2 策略

```
if duration > 30s:
    选取骑行质量最高的 15s 窗口
```

窗口质量评分 = `az 方差 × 1.0 + gz 方差 × 10.0` (越小越好)

- az 方差低 → 路面平整，F1 检测条件好
- gz 方差低 → 骑行笔直，F3 检测条件好

两个指标量纲不同（az 方差 ~0.1，gz 方差 ~0.01），故 gz 方差乘以 10 做量纲归一。

### 6.3 窗口裁剪

选定最优 15s 窗口后，同步裁剪:

- 加速度计数据: 按时间戳筛选在窗口范围内的采样点
- 陀螺仪数据: 同上
- 音频数据: 通过音频时间戳映射表 (`cumulative_samples` 字段) 定位对应采样索引

### 6.4 v3.1 优化: 向量化窗口评分

原始方案逐个窗口做 boolean mask + variance。v3.1 改为:

```python
# 先重采样到 50Hz 统一网格
_, az_uniform = resample_irregular(times_a, az, 50.0)

# 使用 sliding_window_view 一次性获取所有窗口
windows = sliding_window_view(az_uniform, window_samples)[::step_samples]

# 向量化计算所有窗口方差
az_vars = windows.var(axis=1)    # 一次 NumPy 调用替代 N 次 Python 循环
```

将 O(n_windows × window_samples) 的 Python for 循环替换为单次向量化操作，大数据文件场景提速 10× 以上。
